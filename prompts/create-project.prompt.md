## Передумови

- Команду запускають у корені проєкту після `git-init`.
- Доступні навичка `project-scaffold` і правила агента `build-engineer`.
- Не видаляй та не перезаписуй наявні файли без явного дозволу користувача.

## Дії

1. Перевір наявність `src/`, `src/main.cpp` і `tests/`.
2. Створи `src/`, якщо його немає.
3. Створи `src/main.cpp` з `#include <iostream>` і `main()`, що виводить `Hello World!`, якщо файл відсутній.
4. Створи `tests/` для майбутніх модульних тестів, якщо каталогу немає.
5. Якщо `src/main.cpp` уже існує, перевір його вміст. Не перезаписуй файл, якщо він істотно відрізняється від очікуваної мінімальної програми.
6. Переконайся, що кореневий `.gitignore` містить правило `build/`.

## Очікувані файли

- `src/main.cpp` з коректною програмою C++ Hello World.
- Каталог `tests/`.
- Кореневий `.gitignore` з правилом `build/`.

## Повідомлення про помилку

Якщо файл або каталог неможливо створити, `src/main.cpp` має конфліктний вміст або `.gitignore` не можна перевірити, зупини роботу:

> Помилка create-project: конфлікт або помилка під час створення базової структури проєкту. Наявні файли не перезаписано; надайте дозвіл на зміну конфліктного файлу або виправте проблему.
