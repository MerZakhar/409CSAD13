# Інструкція для розробника

## 1. Запуск AI-агента у VS Code

1. Відкрийте корінь репозиторію у VS Code.
2. Відкрийте **GitHub Copilot Chat**.
3. Введіть у чат команду:

```text
Виконай команду init згідно з інструкціями агента build-engineer.agent.md
```

Команда `init` послідовно запускає `git-init`, `create-project`, `create-build`,
`create-actions` і `check`. Якщо будь-який етап завершується помилкою, виконання
зупиняється.

## 2. Локальна конфігурація та складання

Перейдіть у корінь проєкту та виконайте:

```console
mkdir build
cd build
cmake ..
cmake --build .
```

Команда `cmake ..` конфігурує проєкт, а `cmake --build .` збирає виконуваний
файл `hello` і тестовий виконуваний файл.

Якщо каталог `build` уже існує, повторне створення не потрібне. У такому разі
виконайте:

```console
cd build
cmake ..
cmake --build .
```

## 3. Запуск юніт-тестів

Після успішної збірки, перебуваючи в каталозі `build`, запустіть тести через
CTest:

```console
ctest --output-on-failure
```

Параметр `--output-on-failure` виводить детальну інформацію про невдалі тести.
Успішним результатом є проходження тесту `BasicAddition`.
