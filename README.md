## Опис проєкту
Цей репозиторій містить спеціалізованого AI-агента (Build Engineer), розробленого для автоматизації створення кросплатформного "Hello World" проєкту. Агент налаштований за допомогою системи навичок (skills) та команд (commands) для виконання наступних завдань:
1. Генерація структури C++ проєкту та вихідного коду.
2. Налаштування системи складання за допомогою CMake.
3. Інтеграція фреймворку GoogleTest для юніт-тестування.
4. Створення CI/CD pipeline (GitHub Actions) для автоматичного складання та тестування коду на операційних системах Windows, Linux та macOS.
